# Jumpstart よくある質問（FAQ）

## Arc Jumpstart に貢献できますか？

もちろんです！Arc Jumpstart はコミュニティ主導のオープンソースプロジェクトであり、コントリビューションを歓迎しています。始めるには、[Jumpstart コントリビューションガイドライン](../contribution_guidelines/) と [行動規範](https://aka.ms/JumpstartCOC) をご確認ください。

## Arc Jumpstart のドキュメントは AI の助けを借りて作成されましたか？

はい、一部のドキュメントは AI ツールの助けを借りて作成されました。私たちのチームは [Microsoft の AI 生成コンテンツに関する原則](https://learn.microsoft.com/principles-for-ai-generated-content) に従い、品質と精度の高い基準を満たすために AI 支援コンテンツを徹底的にレビューしています。詳細は [AI 免責事項](https://github.com/Azure/arc_jumpstart_docs/blob/main/AI_DISCLAIMER.MD) でご確認いただけます。

## Arc Jumpstart で Azure 無料試用版アカウントを使用できますか？

はい、Azure [無料試用版アカウント](https://azure.microsoft.com/free) を使用できます。ただし、一部の Jumpstart 機能では、無料試用版で提供されていない追加の Azure 使用量が必要になる場合があります。

## Arc Jumpstart は Azure やその他のクラウドプロバイダーへの無料クレジットを提供していますか？

Arc Jumpstart は、Azure やその他のクラウドプロバイダーへの無料クレジットを提供していません。Jumpstart を使用するには、シナリオやソリューションを実行するための独自の環境を提供する必要があります。

## Arc Jumpstart のシナリオとソリューションをデプロイするためにどのような権限が必要ですか？

各 Arc Jumpstart のシナリオとソリューションには、自動化の実行に必要なものが記載されています。前提条件のセクションをご確認ください。ほとんどの場合、サービスプリンシパルの作成が求められるため、Azure の **ユーザーアクセス管理者** または **ロールベースアクセス制御管理者** の権限が必要です。

## Arc Jumpstart は「本番環境対応」と見なされますか？

Arc Jumpstart の目的は、コアとなる Azure Arc、エッジ、IoT の機能、デプロイシナリオ、ユースケース、および使いやすさに焦点を当てることです。Azure のベストプラクティス、コードで活用されているその他の製品やオープンソースプロジェクトには焦点を当てていません。Jumpstart シナリオ、ArcBox、LocalBox、Agora はすべて評価、トレーニング、デモ目的のみを対象としており、本番環境での使用はサポートされていません。

## Arc Jumpstart を使用してデモを実行する方法についてのガイダンスはありますか？

Arc Jumpstart の使用方法に関する追加情報と洞察は、[YouTube チャンネル](https://www.youtube.com/@azurearcjumpstart) でご覧いただけます。

## 何か問題が発生した場合はどうすればよいですか？

問題や質問がある場合は、[GitHub Issue を開いてください](https://aka.ms/JumpstartIssue)。Jumpstart のコアメンテナーまたはコミュニティメンバーができるだけ早く対応します。Azure 製品に関連する問題については、[サポートチケット](https://azure.microsoft.com/support/create-ticket) を開いてください。

## 改善点や機能を提案できますか？

もちろんです！提案がある場合は、[GitHub Feature を開いてください](https://aka.ms/JumpstartFeature)。Jumpstart のコアメンテナーができるだけ早く対応します。また、[GitHub Discussions](https://aka.ms/JumpstartDiscussions) でスレッドを開始することもお勧めします。

## Azure Arc、エッジ、IoT に関する素晴らしいストーリーを Jumpstart コミュニティと共有したいのですが、どうすればよいですか？

ぜひ聞かせてください！[申し込みフォーム](https://aka.ms/LightningGuest) に記入していただければ、すぐにご連絡します。

## Arc Jumpstart のパブリックロードマップはありますか？

Arc Jumpstart シナリオの最新のロードマップは、[リポジトリの GitHub プロジェクト](https://aka.ms/JumpstartRoadmap) でご確認いただけます。

## Jumpstart Drops よくある質問（FAQ）

### Drop に貢献できますか？

Arc Jumpstart Drops は完全にオープンソースであり、Jumpstart Drops の [コントリビューションプロセス](../contribution_guidelines/) に従うすべてのコントリビューションを歓迎しています。ほとんどのコントリビューションでは、コントリビューターライセンス契約（CLA）への同意が必要で、あなたがコントリビューションを行う権利を持ち、実際に Arc Jumpstart チームにコントリビューションを使用する権利を付与することを宣言します。詳細については、[Microsoft CLA](https://cla.opensource.microsoft.com) をご覧ください。

### コントリビューションのソースコードを Jumpstart Drops GitHub リポジトリ内にホストする必要がありますか？

いいえ、コントリビューションのソースコードを Jumpstart Drops リポジトリにホストすることは必須ではありません。コードのホスティングには 2 つのオプションがあり、ユースケースに合ったものを選択できます:

- **プルリクエスト（PR）にコードを含める**: コードを PR の一部として含め、Arc [Jumpstart Drops GitHub リポジトリ](https://github.com/Azure/arc_jumpstart_drops) 内でホストできます。
- **独自のリポジトリにコードを保持する**: または、独自のリポジトリにコードを保持し、Drop [定義ファイル](https://github.com/Azure/arc_jumpstart_drops/blob/main/SCHEMA.md) にその参照/URL を提供することもできます。

### Arc Jumpstart ウェブサイトに貢献したり Jumpstart Drops を使用したりするためにログインが必要ですか？

いいえ、貢献や Jumpstart Drops の使用には認証やログインは必要ありません。ただし、ログインしている場合は、コントリビューターに彼らの貢献に関するインサイトを提供し、体験と申し込みを強化する機能を開発しています。

### Jumpstart Drop のライセンスはどのような仕組みですか？

Jumpstart Drops は、他のすべての Arc Jumpstart 製品と同じ [MIT](https://github.com/Azure/arc_jumpstart_drops/blob/main/LICENSE) ライセンスに従っています。すべてのコントリビューションも [MIT](https://github.com/Azure/arc_jumpstart_drops/blob/main/LICENSE) ライセンスの下である必要があります。

MIT ライセンスは、元の著作権表示とライセンス条項がソフトウェアのコピーまたは配布物に含まれている限り、ライセンスされたソフトウェアの使用、変更、配布を許可する寛容なオープンソースソフトウェアライセンスです。

詳細については、[コントリビューションプロセス](../contribution_guidelines/) をご覧ください。

### Jumpstart Drop を見つけるにはどうすればよいですか？

ニーズに合った Jumpstart Drop を見つけるには、Arc Jumpstart Drops のメインページで利用可能なフィルターと並べ替えオプションを活用してください。まず [Arc Jumpstart Drops](https://aka.ms/JumpstartDrops) にアクセスし、右側のパネルを使用して *プログラミング言語*、*製品*、*難易度*、*業種*、*トピック* などの条件でフィルタリングします。また、上部の検索バーを使用して、Jumpstart Drops を含むすべての Jumpstart コンテンツを検索することもできます。

### Jumpstart Drop を使用するにはどうすればよいですか？

Jumpstart Drop の使用は簡単です。Jumpstart Drop のページにある「ダウンロード」ボタンをクリックして Drop をダウンロードします。ダウンロード後、Jumpstart Drop を実行するために必要なすべてのソースコードを含む *.zip* ファイルが手元に届きます。Jumpstart Drop によっては、いくつかの前提条件の設定が必要な場合がありますが、すべての指示は Jumpstart Drop の *index.md* ファイルに含まれているはずです。

### Jumpstart Drop を申し込むにはどうすればよいですか？

Jumpstart Drop の申し込みは簡単で、Arc Jumpstart Drops リポジトリに直接コンテンツをアップロードしてプルリクエストを作成します。
詳細な手順については、Jumpstart Drops の [コントリビューションプロセス](../contribution_guidelines/) ガイドを参照してください。

### Jumpstart Drops のサポートとメンテナンスはどのように処理されますか？

Jumpstart Drops のサポートとメンテナンスは GitHub Issues を通じて管理され、バグや機能リクエストを追跡できます。このプロジェクトは [Arc Jumpstart サポート](https://github.com/Azure/arc_jumpstart_docs/blob/main/SUPPORT.md) に概説されているサポートアプローチに従っています。

**重要**: _Jumpstart Drops には公式サポートや保証は付いていませんが、コミュニティができる限り支援することが奨励されていることにご注意ください。_

### このプロジェクトではコードメンテナンスにどのようなツールが使用されていますか？

すべての Jumpstart Drop オーナーは、ソースコードのコードメンテナンスを担当しています。Jumpstart Drops リポジトリの一部として Jumpstart Drop のソースコードをホストすることを選択した場合、**CodeQL** や **GitHub Dependabot** のセキュリティアラートなど、コードメンテナンスのためのチェックを実行します。コントリビューターがソースコードを維持するための新しい機能の開発に積極的に取り組んでいます。提案がある場合は、提案するアプローチと共に [Issue](https://github.com/Azure/arc_jumpstart_drops/issues/new?assignees=fcabrera23&labels=triage&projects=&template=%F0%9F%90%9Bbug-report.md&title=) を作成してください。
