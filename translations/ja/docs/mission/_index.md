## 私たちのミッションと原則: シームレスな Azure アダプティブクラウド導入の支援

Arc Jumpstart のコアミッションは、従来の製品ドキュメントと Microsoft テクノロジーの「現実世界」への応用ソリューションとの間の「ミッシングリンク」を提供することです。アダプティブクラウドポートフォリオは、Microsoft の顧客やパートナーに価値をもたらします。このミッションへのコミットメントは、私たちを前進させる原則に根ざしています:

1. **価値実現までの時間** Arc Jumpstart は、シームレスな「ゼロからヒーローへ」の体験を提供するよう設計されています。私たちはあなたの時間の価値を理解しており、Azure アダプティブクラウド製品ポートフォリオに直接飛び込めるよう、計画中のソリューション導入の障壁と複雑さを排除することを目標としています。

2. **包括的なガイダンス:** ガイドを提供するだけでなく、現実のユースケースとシナリオに合わせた包括的なステップバイステップの指示を提供します。コンテンツは細部まで丁寧に作成されており、簡潔な指示、明確なスクリーンショット、自動化を使用してセットアップ時間と複雑さを軽減する包括的なコードサンプルが含まれています。

3. **卓越したユーザーエクスペリエンス:** 豊かな体験を提供したいので、初心者と経験豊富なプロフェッショナルの両方に響くコンテンツを提供することで基本を超えています。オンプレミスでもクラウドでも環境をセットアップしているかどうかにかかわらず、私たちのガイドにより、不必要な技術的困難に悩まされることなく製品の評価に集中できます。

4. **プラットフォームの柔軟性の受け入れ:** インフラの多様性を認識しており、私たちのミッションはプラットフォームに依存しないアプローチを提供することです。Arc Jumpstart は、オンプレミスまたはクラウドにあるかどうかにかかわらず、あなたのインフラに対応します。セットアップに関係なく、アダプティブクラウドアプローチと製品ポートフォリオの真の可能性を楽に活用できるよう焦点を当てています。

## 私たちの哲学とコアデザイン原則

Arc Jumpstart では、ドキュメントやガイドを作成するだけでなく、個人的なレベルであなたに響くことを願った没入型の体験を作り上げています。私たちの哲学は、これらのコアデザイン原則に深く根ざしており、私たちの素材とのすべてのインタラクションを豊かで親しみやすいものにすることを目標としています:

1. **「ユーザーは失敗しない」というメンタリティ:** あなたの成功が私たちの最優先事項です。すべてのガイドで確実で使いやすい指示を提供することを目指しています。また、ユーザーの問題やディスカッションのための活発なコミュニティを GitHub で運営しています。

2. **自動化の卓越性:** 自動化できるものや自動化すべきものは、確実に自動化されます。私たちは自動化の力を信じており、プロセスを合理化し、複雑なタスクを簡素化して、あなたの旅をスムーズで効率的にします。

3. **レゴのようなモジュール性:** レゴのようなコーディングに似たモジュール型自動化の哲学を採用しています。コンテンツは再利用可能、包括的、反復可能、そして何よりも信頼性が高いように設計されています。ビルディングブロックのように、これらのモジュールは堅牢でスケーラブルなソリューションに組み立てられ、あなたのニーズに合わせて調整されます。

4. **デプロイの包括性:** 環境の多様性を認識して、できるだけ多くのデプロイオプションをサポートしています。インフラに関係なく、ガイドはシームレスな統合を確保するように調整されており、私たちが提唱するテクノロジーをすべての人が利用できるようにしています。

5. **細部への注意:** どんな細部も私たちには重要です！必要なすべてのスクリーンショット、注意事項、免責事項、説明を含めることを心がけているので、不必要な質問に時間を無駄にする必要はありません。

6. **イノベーションの採用:** パブリックプレビューと一般提供（GA）のサービスと機能のみに焦点を当て、最新のイノベーションと機能へのアクセスを確保しています。

## オープンソースコミュニティへのコミットメント: 共に卓越性を高める

Arc Jumpstart では、高いコード品質を優先事項としてだけでなく、基本原則として考えています。シナリオや機能のための広範な自動化とスクリプトは厳格なコードレビューとテストを受け、ユーザーが信頼できる卓越性の基準を確保しています。品質は細心の職人技に関することだけでなく、適切なツールを選択し効果的に統合することでもあると考えています。

オープンソースコラボレーションの精神の中で、私たちはより広いコミュニティを支援することに深くコミットしています。他者の顕著な貢献を認識し、その作業の上に構築する機会を積極的に求めています。多くの人気のオープンソースプロジェクトが Jumpstart に統合されており、私たちのコミットメントは単なる使用を超えています。これらのプロジェクトを支援、提唱、貢献することを誓い、相互成長と革新の環境を育成しています。

このエトスを採用することで、比類のないオープンソース体験を提供することに専念しています。共に、オープンソースの卓越性の基準を高め、革新の限界がない活気あるコミュニティを作りましょう。

## Jumpstart ユニバースを始める

このウェブサイトは、アダプティブクラウド体験を開始するために必要なすべてを確保するよう厳選されています。詳細なガイド、自動化ツール、コードサンプル、スクリーンショット、およびダイアグラムを探索するための包括的なプラットフォームを提供しています。

![Jumpstart ユニバースを示す画像](/img/about/universe.png)

**期待できること:**

- **包括的なガイド:** あらゆるレベルのユーザーに対応したステップバイステップの指示が提供されています。初心者でも経験豊富なユーザーでも、私たちのガイドは明確で簡潔、わかりやすいように設計されています。

- **効率的な自動化:** 自動化により複雑なタスクが簡素化され、効率が向上します。自動化ツールはプロセスを合理化するように調整されており、作業のコア側面に集中できます。

- **洞察力のあるコードサンプル:** 実践的な自動化とコードサンプルがハンズオン学習を促進します。厳選されたサンプルで実験し、アダプティブクラウドのアプローチ、概念、機能についてより深い理解を得てください。

- **視覚的学習:** 視覚的なキューが理解を高めます。詳細なスクリーンショットが視覚的なコンテキストを提供し、学習体験を向上させ、複雑なトピックをより身近にします。

> **免責事項:** Arc Jumpstart は、アダプティブクラウド製品ポートフォリオと機能、デプロイシナリオ、および実践的なユースケースに焦点を当てています。広範なサポートを提供しますが、Azure のベストプラクティスと、シナリオおよびコード内のさまざまなテクノロジーおよびオープンソースプロジェクトの統合は、私たちの主要な範囲外であることにご注意ください。ArcBox、LocalBox、Agora を含むシナリオは、評価、トレーニング、デモ目的のみを対象としており、本番環境での使用を意図したものではありません。
